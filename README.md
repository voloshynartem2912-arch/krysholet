# Крышелёт — онлайн-версия 2.0

Игра (`public/index.html`) + сервер на Node.js: **11 глав**, рейтинг, магазин с лимитированными вещами, уровни игроков, игра вместе (WebSocket).
Деньги, время и покупки считает **сервер** — клиенту верить не нужно.

## Запуск локально
    npm install
    npm start          # http://localhost:3000

## Выложить на Render (бесплатно)
1. Залей папку в репозиторий на GitHub.
2. render.com → **New → Blueprint** (или Web Service) → выбери репозиторий. `render.yaml` подхватится сам.
3. Подключи **постоянную базу** (иначе после каждого «засыпания» кошельки и покупки стираются — бесплатный диск Render временный):
   - upstash.com → Create Database (Redis, бесплатный план) → вкладка **REST API** → скопируй `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`;
   - в Render → Environment → вставь обе переменные. Всё. Если база недоступна при старте, сервер сам не запустится — чтобы не затереть данные.
   - Альтернатива — платный Render Disk: примонтируй в `/data` и задай `DATA_FILE=/data/data.json`.
4. В Environment уже есть `ADMIN_KEY` (Render сгенерирует) — это пароль для админки.

### Переменные окружения
| Переменная | Для чего |
|---|---|
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | постоянная база (рекомендуется) |
| `DATA_FILE` | файл базы, если без Upstash (по умолчанию `data.json`) |
| `EXPORT_SECRET` | подпись файлов экспорта аккаунта (Render генерирует сам; не меняй — старые файлы перестанут приниматься) |
| `ADMIN_KEY` | пароль админки, минимум 12 символов; без него админка выключена |
| `TRUST_PROXY_HOPS` | сколько прокси перед сервером (Render = 1, по умолчанию 1; локально поставь 0) |
| `PORT` | порт (Render задаёт сам) |

## Как работает античит
Клиент записывает **нажатые кнопки на каждый тик физики** (1/60 с) и по финишу отправляет запись. Сервер прогоняет её через тот же `public/sim.js` и **сам** считает время, монеты, финиш и очки. Поэтому нельзя прислать «я прошёл за 3 секунды» или «я собрал 999 монет» — только запись, которая реально это даёт.
Физика сделана детерминированной (свои `sin/cos/exp/atan2` вместо `Math.*`), результат одинаков в Node и в Chromium — проверено тестом `tools/det.js`.
Дополнительно: токен у каждого игрока (хранится только хеш), лимиты запросов (по IP и по игроку), награда за повторные прохождения ограничена по времени забега и числу в час, версия физики сверяется (после обновления сервер просит обновить страницу), сохранение в игре — это тоже запись, поэтому подделать «сохранение на чекпоинте» нельзя.

**Честные границы:** бота, который «нажимает кнопки» по-настоящему (TAS, автокликер, программа-проходчик), отличить от человека нельзя — запись выглядит как обычная. От него защищают только лимиты наград в час (`ECON.repeatPerHour`) и рейтинг по времени, который можно проверять глазами. Бан — в админке.

## Магазин и экономика
Всё в `lib/shop.js`:
- `ITEMS` — предметы. `limit: N` — сколько штук **на весь сервер** (кто успел). Один игрок — одна копия.
  Лимитированные: скины Призрак (30 шт, 1 500), Магма (15, 3 000), Радуга (8, 6 000), Космонавт «Зенит» (4, 12 000); значки Ракета (20, 2 500), Молния (10, 4 500), Корона (2, 20 000). Значок показывается в рейтинге и над призраком в игре.
- `ECON` — заработок: 1 монета за каждую впервые подобранную, 20 за первое прохождение карты, потом `10 + 4 × номер главы` за повтор (не быстрее 15 с и не больше 24 в час).
Чтобы поменять цены или добавить предмет, правь `ITEMS`. Новый скин ещё нужно добавить в `SKINS` в `public/index.html` (цвета), id должен совпасть.

### Админка
    curl -H "x-admin-key: $ADMIN_KEY" https://ТВОЙ-САЙТ/api/admin/stats
    curl -H "x-admin-key: $ADMIN_KEY" -H "content-type: application/json" -d '{"id":"ID","amount":500}' https://ТВОЙ-САЙТ/api/admin/grant     # выдать монеты
    curl -H "x-admin-key: $ADMIN_KEY" -H "content-type: application/json" -d '{"id":"ID","banned":true}' https://ТВОЙ-САЙТ/api/admin/ban      # бан / разбан
    curl -H "x-admin-key: $ADMIN_KEY" -H "content-type: application/json" -d '{"item":"skin9","add":2}' https://ТВОЙ-САЙТ/api/admin/restock # +2 штуки лимитки

Аккаунт игрока — токен в браузере. В игре: Магазин → «Аккаунт» → там код входа, по нему можно зайти с другого устройства.

## Экспорт аккаунта (защита от стирания на Render)
В игре: Магазин → «Аккаунт» → **Скачать копию** (файл `krysholet-<id>.json`) и **Восстановить из файла**.
- Файл подписан сервером (`EXPORT_SECRET`), поэтому поправить в нём монеты или вещи нельзя — подпись сломается.
- Файл **привязан к коду входа** игрока (внутри хеш токена). Чужой человек с файлом ничего не сделает: восстановление требует код входа. Файл без кода бесполезен.
- Восстановить можно только аккаунт, которого **сейчас нет** на сервере. Если он есть — отказ (409), поэтому файл нельзя использовать, чтобы размножить монеты или вещи. Купленные лимитки при восстановлении снова считаются в «раскуплено».
- Если Render стёр базу, браузер хранит старый код входа (`pk_tok_old`) и подставляет его сам: достаточно выбрать файл и нажать «Восстановить». С другого устройства — сначала вставь код входа в поле.
- Не теряется только то, что в файле: имя, кошелёк, покупки, рекорды, собранные монеты. Незавершённые сохранения глав и награды за последний час не переносятся.
- Честно: если игрок сам отдаст другому **и файл, и код**, тот получит аккаунт — но код входа и так даёт полный доступ к аккаунту.

## Уровни
11 глав: город, озеро, лес, подводный мир, горы, космос, **завод, пустыня, вулкан, небесные острова, башня**. Описаны в `public/sim.js` (функции `buildFactory` и т.д.). Чтобы добавить главу: функция-строитель → запись в `BUILDERS` и `CHAP` → оформление (фон, названия, история) в `index.html`.
`npm run verify-levels` запускает бота: он проходит каждую карту и доказывает, что она проходима (`node tools/bot.js factory,desert 1 150000 tools/replays` — только указанные карты).

## Если игра обновилась
Версия физики (хеш `sim.js`) сверяется автоматически. После изменения `sim.js` старые **сохранения** и неотправленные записи перестанут проигрываться так же — игрокам просто придётся начать главу заново; на баланс и покупки это не влияет.
